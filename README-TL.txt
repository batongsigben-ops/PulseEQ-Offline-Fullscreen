PULSEQ OFFLINE FULLSCREEN - GIGAMIT SA ANDROID PHONE

KINI USA KA BAG-ONG ANDROID PROJECT, DILI PA ANG APK.
Features:
- Native Android app; walay website nga i-load.
- Walay INTERNET permission; mahimong mopili ug audio file nga naa sa phone.
- Fullscreen/immersive mode; swipe gikan sa ngilit aron ipakita ang system bars.
- Play/pause/stop, volume, ug equalizer nga nagsalig sa audio effect nga suportado sa phone.
- Automatic cloud build pinaagi sa GitHub Actions.

IMPORTANTE:
- Ang gidaghanon sa EQ bands magdepende sa audio hardware sa phone; ang UI nagpakita sa actual bands nga gihatag sa Android device.
- Dili pa kini gi-test sa imong specific phone. Human sa build, i-test ang audio picker, playback, ug EQ.
- Ang APK nga gihimo sa GitHub Actions kay debug APK alang sa personal testing. Ayaw ipaambit ang imong GitHub password o verification codes.

PAG-BUILD GAMIT ANG ANDROID PHONE:
1. Ablihi ang github.com sa browser ug sign in.
2. Paghimo og repository nga ngalan: PulseEQ-Offline-Fullscreen. Pilia ang Public o Private sumala sa gusto nimo; ayaw pagdugang og README/license kay naa na kini sa ZIP.
3. Ablihi ang repository > Add file > Upload files.
4. I-unzip kini nga ZIP gamit ang file manager sa phone.
5. Upload ang sulod sa folder (dili ang ZIP mismo), apil ang .github folder. Kung dili makita ang .github, i-on ang Show hidden files o upload files gamit ang browser desktop-site mode.
6. Commit changes.
7. Ablihi tepa Actions tab > Build PulseEQ Offline APK > Run workflow.
8. Hulata nga mahuman ang build. Ablihi ang run nga green check, scroll sa Artifacts, ug i-download ang PulseEQ-Offline-Fullscreen-APK.
9. Unzip ang artifact ZIP aron makuha ang app-debug.apk.
10. I-install ang APK ug sulayi ang airplane mode/offline playback.

Kung dili makita ang Add file/Actions sa cellphone, sulayi ang browser menu > Desktop site.
